# はじめに

watsonx Orchestrate でエージェント資産を運用管理する方法を体験するハンズオンです。
主に Control Plane の機能や操作方法を中心に学習します。

|#|内容|所要想定時間(分)|
|:---:|------------------------------------------------------------------|:---:|
|[Lab1](intro.md)|画面の確認と事前準備|15|
|[Lab2](analyze.md)|エージェントの分析|15|
|[Lab3](control.md)|エージェントの管理・統制|20|
|[オプション](op-voice.md)|音声エージェント|-|


## 前提条件

 1. watsonx Orchestrate の環境にアクセスできること
 2. watsonx Orchestrate において Service admin（管理者）の権限を持っていること

製品のマニュアルについては、<a href="https://www.ibm.com/docs/ja/watsonx/watson-orchestrate/base" target="_blank" rel="noopener noreferrer">こちら</a> を参照ください。  
Control Plane については <a href="https://www.ibm.com/docs/ja/watsonx/watson-orchestrate/base?topic=operating-agentic-control-plane-overview" target="_blank" rel="noopener noreferrer">こちら</a> に記載されています。
